# v0.5.0

Adds `docs/validation.md`, the library checked against closed-form answers
and published magnitudes, with the numbers produced by
`examples/validate.py` and the failures reported rather than tuned away. Also
a new `lobster.execution` module for book-walk and metaorder costs, a worked
example that hands a measured cost curve to a portfolio problem, and
randomized property tests for the engine and the estimators. See
CHANGELOG.md.
